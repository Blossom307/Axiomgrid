# Axiom Grid

A responsive marketing site for **Axiom Grid**, a fictional industrial 3D intelligence platform for construction systems, robotics simulation, and automation control.

> **Concept project.** The company, team, deployments, and statistics shown are fictional and created for design and front-end practice.

**Live site:** https://axiomgrid.netlify.app

![Axiom Grid Digital Twin Command Center](images/twincmdcentre.png)

## About

I designed this as a product-style landing page to practice building a distinctive, technical visual identity from scratch. The idea draws on my background in Building Technology Education and my interest in software, imagining what a unified platform for construction and robotics could look like.

## Features

- Responsive layout that adapts to desktop and mobile screens
- Sections for platform capabilities, a layered architecture overview, active deployments, simulation environments, team, and system status
- Terminal-style visual theme with simulated live telemetry readouts
- Smooth in-page navigation between sections
- Request-access form styled as a command-line interface

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)
- Deployed on Netlify

## Project Structure

```
Axiomgrid/
├── images/       # logo and simulation visuals
├── index.html    # page structure and content
├── styles.css    # layout, theme, and responsive styles
└── script.js     # interactions and simulated telemetry
```

## Run Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/Blossom307/Axiomgrid.git
   ```
2. Open the folder and double-click `index.html`, or serve it with any static server.

No build step or dependencies are required.
